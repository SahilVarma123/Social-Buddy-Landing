# Social Buddy

React Native + Expo application for the VecnaVerse hackathon, Problem Statement 1: Hyperlocal Event Discovery & Community Engagement.

## Development

The app is built with Expo and TypeScript. Use `npm install` and `npx expo start` to run the local development server.

## Git workflow

Work directly on `main` for this hackathon. After each coherent, validated change, commit and push to `origin/main`. Never push secrets, `.env` files, or credentials. Before pushing, run type checks and relevant validation; inspect `git status` and `git diff` first.
